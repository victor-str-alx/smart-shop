📊 TF-IDF Content-Based Filtering

Cum Funcționează?

  • Step 1: Extrage descrieri produse
  • Step 2: Vectorizare text → numere
  • Step 3: Calcul cosine similarity
  • Step 4: Recomandă Top N

Exemplu

User a cumpărat:
"Laptop Gaming ASUS"

→ Recomandă:
• Monitor Gaming LG
• Mouse Gaming
• Tastatură Mecanică

👥 Collaborative Filtering

User-Item Matrix

Prod1 Prod2 Prod3 Prod4 User A 1 0 1 0 User B 1 1 0 1 ← Similar cu A User C 0 1 1 0

Exemplu Real

Ana și Maria au cumpărat produse similare
→ Ana primește recomandări din comenzile Mariei
→ Maria primește recomandări din comenzile Anei
